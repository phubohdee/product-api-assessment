# Product API Assessment

This is a RESTful API service built with Go for managing products.

## Prerequisites

- [Go](https://golang.org/) 1.20+
- Database (Specify if applicable)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/phubohdee/product-api-assessment.git
   ```
2. Navigate into the project directory:
   ```bash
   cd product-api-assessment
   ```
3. Install dependencies:
   ```bash
   go mod tidy
   ```
4. Run the application:
   ```bash
   go run cmd/api/main.go
   ```
